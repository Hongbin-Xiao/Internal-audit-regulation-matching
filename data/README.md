# 数据说明

## eval138_anon.json

138 条真实内部审计问题，每条含专家标注的标准答案。用于论文表 5—7 的消融、外部对照与跨机构统计。

| 字段 | 含义 |
| --- | --- |
| `ds` | 问题分组代号（G1 / G2 / T1 / T2），对应不同被审计单位与审计领域 |
| `q` | 问题定性短语，如「部门预算编制不完整。」 |
| `desc` | 问题描述，含业务背景与违规事实，金额已脱敏 |
| `std` | 专家标注的标准答案，即应引用的法规条款原文 |
| `labels` | 各配置的判定结果：`2` 条款级命中 / `1` 仅文件级命中 / `0` 无效 |

### 脱敏处理

| 类别 | 处理 |
| --- | --- |
| 被审计单位 | 甲校 / 乙校 / 丙校 / 丁校，与 `ds` 分组代号一一对应；机构全称与简称统一替换 |
| 附属机构 | 附属中学、后勤集团、附属医院、出版社、书店等记为「某中学」「某集团」等 |
| 校内部门 | 各二级学院、中心、处室记为「某学院」「某中心」 |
| 企业 | 记为「某公司」 |
| 校区与地名 | 记为「某校区」「某市」「某区」「某县」 |
| 内部制度 | 标题中的单位名替换为「某校」「乙校」等，如《某校差旅费管理办法》 |
| 金额与数量 | `***万元`、`***项`、`***个` |

原始名称与代号的对应关系仅保存在作者处，不随仓库公开。

### 脱敏复核

用脚本抽取全部疑似专有名词（机构后缀、地名后缀、《》标题）逐条核对，并对全库做正则扫描，以下项命中均为 **0**：

机构全称与简称、公司名、校内部门、校区名、身份证号、银行账号、硬编码密钥、本机绝对路径、邮箱与手机号。

`std` 字段中的公开法规名称（如《事业单位国有资产管理暂行办法》）保持原样，未做替换。


### 使用

```bash
cp data/eval138_anon.json _exp/eval138.json
```

脚本按 `_exp/eval138.json` 读取，字段名与上面一致。

## 法规语料（不随仓库分发）

论文实验使用 1 285 份法规、约 822 万字符，切分为 39 838 条条款级语义片段。语料未随仓库提供，原因有二：总量约 156 MB；其中「单位内部制度」一层属被审计单位内部资料。

可公开获取的部分及来源：

| 层级 | 来源 |
| --- | --- |
| 国家法律与党内法规 | 中国人大网、国家法律法规数据库、审计署「应知应会法律法规」 |
| 部委规章与规范性文件 | 财政部法规库、审计署审计常用法规向导 |
| 地方性规定 | 广西壮族自治区人民政府、自治区财政厅公开文件 |
| 单位内部制度 | **不含**（内部资料） |

### 预处理要点

1. 大量 `.doc` 实为 MHTML 网页存档（论文中 945 份），常规文档解析库会失败，需按 MIME 解码、还原传输编码后剥离标签。
2. 按「第 X 条」切分，一条法规的相邻条款各自成片段；未命中条号的按固定长度切分。
3. 同名文件按内容哈希去重；含标准答案的目录类文件（如「审计问题定性法规向导」）须排除，否则评测会泄漏。
4. 每条片段保留 `name`（法规名称）、`file`（来源文件）、`text`（条文）三个字段，`chunk_corpus.mjs` 输出此格式。
